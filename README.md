# Laboratorios de Dart

Repositorio de actividades prácticas del programa de formación ADSO, enfocado en el aprendizaje de programación con Dart.

## Laboratorio 01: Fundamentos de Dart

Primer acercamiento al lenguaje Dart mediante ejercicios de lógica y programación.

**Repositorio:** [dart-laboratorio-01](https://github.com/Fhellips/dart-laboratorio-01)

## Laboratorio 02: Estructuras de control y programación

Desarrollo de ejercicios prácticos sobre condicionales, ciclos, funciones y lógica de programación.

**Ejecutar los programas principales:**

```bash
dart run bin/agricultural_explorer.dart
dart run bin/cinema_ticket_sales.dart
```

## Laboratorio 03: Funciones y colecciones

Desarrollo de ejercicios utilizando funciones y estructuras de datos como `List`, `Set` y `Map`.

Se incluyen dos proyectos integradores:

- **AgroDiversa:** catálogo de observaciones agrícolas por municipio, año y cultivo.
- **Catálogo de biblioteca:** registro, búsqueda y organización de libros por código y género.

**Ejecutar AgroDiversa:**

```bash
cd lab-03/dart_lab_03
dart run bin/agricultural_catalog.dart
```

**Ejecutar el catálogo de biblioteca:**

```bash
dart run bin/catalogo_biblioteca.dart
```

## Requisitos

- Tener instalado [Dart SDK](https://dart.dev/get-dart).
- Tener Git instalado para clonar y gestionar el repositorio.

## Verificación

Para analizar el código del Laboratorio 03:

```bash
cd lab-03/dart_lab_03
dart analyze
```

Para ejecutar las pruebas:

```bash
dart test
```
